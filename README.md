# Loans Data Analytics Project

What began as a general data analytics project gradually became a more focused, SQL-based exploration of loan data. The _init_ folder holds the initial research and study materials for the Loans Data Analytics Project.

## The wider project

The work has since grown beyond these initial materials. It includes the SQL work and Creditbook, a credit dashboard app built with React. Power BI and other tools may be explored later, but they are not part of the project for now.

## How this project came together

AI tools helped substantially with the research and learning behind this work. Using them has made me think about how much technology can help us explore unfamiliar topics and make progress. The project is still developing, and this folder records where that journey began.
